# Loterías App

Resultados de loterías internacionales, comenzando por Estados Unidos.

## Quick start

```bash
flutter pub get
dart run build_runner build --delete-conflicting-outputs
flutter run
```

Para el contexto completo del proyecto (decisiones de arquitectura, roadmap,
estado actual), consulta **[PLAN.md](./PLAN.md)** — es el documento que debe
leerse primero al retomar el trabajo.
